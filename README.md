
# FoodVerse AI

## Multimodal AI-Powered Food Intelligence Platform

FoodVerse AI is a college project that aims to use Artificial Intelligence, Machine Learning, Computer Vision, and Large Language Models to provide intelligent food-related insights.

## Project Overview

The platform aims to combine food image analysis, freshness assessment, restaurant hygiene monitoring, cooking assistance, and personalized meal planning in one system.

## Project Objectives

- Recognize food items from images.
- Estimate nutritional information for recognized food.
- Assess visible indicators associated with food freshness.
- Explore restaurant hygiene monitoring using computer vision.
- Generate recipes and cooking guidance.
- Create personalized meal plans based on user preferences.

## Technology Stack

- **Programming Language:** Python
- **Backend:** FastAPI
- **Frontend:** ReactJS
- **Computer Vision:** OpenCV
- **Deep Learning:** PyTorch
- **Language Models:** Meta LLaMA models
